# EuropaGrad

Find, verify, filter, rank, track, and export funded European Master's programs for Bangladeshi CSE students — evidence-cited data produced by a Python research agent, served through a fast Next.js app.

**Start here:** [AGENTS.md](AGENTS.md) → [docs/state.md](docs/state.md) → [docs/tasks.md](docs/tasks.md)

## Quick start

```powershell
npm i -g pnpm
pnpm install
cd apps/agent; uv sync
copy .env.example apps\web\.env.local
copy .env.example apps\agent\.env
```

Full setup, architecture, and workflow docs live in `AGENTS.md` and `docs/`.
